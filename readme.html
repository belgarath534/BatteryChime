BatteryChime

BatteryChime plays audio warnings when your battery reaches low, critical, and emergency levels. Never get caught with a dead battery again!

Features

  • Three warning levels: Low, Critical, and Emergency
  • Fully customizable warning percentages for each level
  • Choose from a built-in sound pack or use your own WAV file
  • Test buttons to preview each warning sound
  • Adjustable battery check interval
  • Warnings only play when unplugged

Default Warning Levels

  • Low: 20 percent
  • Critical: 10 percent
  • Emergency: 5 percent

How to Use

  1. Open NVDA menu with NVDA+N
  2. Go to Preferences, then Settings
  3. Find the BatteryChime category
  4. Configure your warning levels and sounds
  5. Use the Test buttons to preview each sound
  6. Press OK to save
