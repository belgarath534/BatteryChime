# BatteryChime

An NVDA add-on that plays audio warnings when your battery reaches low, critical, and emergency levels, and lets you know when the charger is plugged in, unplugged, or the battery is fully charged.

## Features

- Three battery-level warnings: Low, Critical, and Emergency
- Charging events: Plugged In, Unplugged, and Fully Charged
- Fully customizable warning percentages for each level
- Choose from 13 built-in sounds or use your own WAV file, independently for each event
- Test buttons to preview each sound
- Adjustable battery check interval
- Battery-level warnings only play when unplugged

## Default Warning Levels

| Level | Percentage |
|---|---|
| Low | 20% |
| Critical | 10% |
| Emergency | 5% |
| Fully Charged | 100% |

## Installation

Download the latest `BatteryChime.nvda-addon` from the [Releases page](https://github.com/belgarath534/BatteryChime/releases), then open it to install into NVDA.

## Configuration

1. Open the NVDA menu with `NVDA+N`
2. Go to Preferences, then Settings
3. Find the BatteryChime category
4. Configure your warning levels and sounds
5. Use the Test buttons to preview each sound
6. Press OK to save
